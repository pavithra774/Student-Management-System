# Student Management System

## 📌 Project Overview

The Student Management System is a Python-based desktop application developed to manage student records efficiently. It allows users to add, update, delete,
and view student details using a simple graphical user interface.

## 🚀 Features

- Add new student records
- View student details
- Update existing student records
- Delete student records
- Clear input fields
- Store student data using SQLite database
- User-friendly graphical interface

## 🛠️ Technologies Used

- Python
- Tkinter
- SQLite
- VS Code
